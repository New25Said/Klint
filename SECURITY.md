# Política de Seguridad — Klint AI

Tomamos la seguridad de **Klint AI** muy en serio. Si descubres alguna vulnerabilidad de seguridad en este bot, API web o panel de administración, te agradecemos que nos lo informes de manera responsable.

## Versiones Soportadas

| Versión | Soportada |
| :--- | :--- |
| `main` (Render Live) | ✅ Sí |
| Versiones antiguas | ❌ No |

## Reportar una Vulnerabilidad

**NUNCA abras un Issue público en GitHub para reportar un fallo de seguridad.**

En su lugar, por favor sigue estos pasos:

1. Ponte en contacto directamente con el desarrollador principal (**Said Sandoval Pérez**) a través de Discord o mensaje privado.
2. Describe detalladamente la vulnerabilidad encontrada y los pasos exactos para reproducirla.
3. Proporciona tiempo suficiente para solucionar el fallo antes de hacer pública cualquier información.

### Lo que prometemos:
* Responderemos a tu reporte lo antes posible.
* Solucionaremos la vulnerabilidad en el menor tiempo posible antes de desplegar en producción.
